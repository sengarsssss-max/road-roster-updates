# Road Roster — updates

This page only holds the built files the Road Roster app downloads by itself:

- `RoadRoster.apk` — the app (latest release)
- `version.json` — what the app checks when you say "पहलवान, अपडेट देखो"
- speech model pack (Vosk Hindi, Apache-2.0) and all-India map pack (© OpenStreetMap contributors, ODbL)

No source code is kept here.

Install by hand: download `RoadRoster.apk` from the latest release and install it over the old app.
